# Use RepDawn without cloud

The standalone `RepDawn.html` needs no setup. Open it in a browser, create cards, study both directions, and export JSON backups regularly. It does not load scripts or vocabulary from the internet.

The native Android app stores cards in a local Room database. Create cards and study in airplane mode. Use **Settings → Export backup** for a full ZIP backup or **Export CSV** to edit vocabulary on a laptop. After editing, use **Import CSV** on Android to merge the updates. Cards absent from the CSV are not deleted.

No login or cloud account is needed. Automatic cross-device cloud sync is not active in this source package; CSV/JSON file transfer is the working no-cloud bridge.
