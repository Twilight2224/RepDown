# Laptop editor

For the simplest laptop experience, open the root-level `RepDawn.html` file in Chrome, Edge, or Firefox. It works offline and has the same basic flashcard workflow as the phone browser version. Use **Transfer & backup → Download CSV** to export editable vocabulary; send the CSV to the phone and import it there.

The older React editor remains in `web-editor/`. It uses browser local storage and requires Node.js plus `npm install` to run. It is not required for the one-file workflow.
